## My Project Proposal

**What I'm building:**  
I'm building a Python text analysis tool that explores themes, character focus, and language patterns in *Little Women* by Louisa May Alcott.

**Why I chose this:**  
I chose this because I enjoy literature and want to combine it with data analysis to better understand how characters and themes develop throughout the book. This helps me see patterns that are not obvious just by reading, like which characters dominate certain chapters or how emotional tone changes over time.

**Core features:**  
- Load and clean the full text of *Little Women*  
- Count and compare how often each main character appears  
- Analyze word frequency to identify key themes (e.g., family, love, growth)  
- Track how language or tone changes across chapters  
- Visualize results using simple charts (word counts, trends over time)

**What I don't know yet:**  
- How to properly clean and format raw book text for analysis  
- How to handle variations in character names (e.g., Jo vs Josephine)  
- How to measure “tone” or sentiment in a meaningful way  
- How to split the book into chapters programmatically  
- How to choose the most useful visualizations for storytelling

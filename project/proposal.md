## My Project Proposal

**What I'm building:**  
A Python-based simulation and financial modeling tool that analyzes the user growth and revenue potential of my dance networking startup idea, Cypher.

**Why I chose this:**  
I chose this because I’m actively building Cypher as a real venture, and I want to understand the numbers behind it instead of just the idea. In my business plan, I projected user growth, premium conversions, and break-even at 2,000 premium subscribers, but I haven’t actually simulated different financial scenarios in code. This project helps me test “what if” situations like slower growth, different conversion rates, churn, or pricing changes. Instead of guessing whether the business model works, I can model it and see the impact of different assumptions.

**Core features:**
- Simulate monthly user growth (free vs. premium users)
- Model multiple revenue streams (subscriptions, job postings, featured listings)
- Calculate monthly expenses and net cash flow
- Run break-even and sensitivity analysis (e.g., conversion rate or pricing changes)
- Visualize revenue, costs, and profit trends over time using Python graphs

**What I don't know yet:**
- How to structure a clean, modular financial simulation in Python
- How to realistically model churn and user conversion behavior
- The best way to run and compare multiple scenario simulations
- How to create clear, professional visualizations
- Whether to use pure Python or integrate pandas and matplotlib for better analysis


## What I learned this week

This week focused on text analysis and how Python can be used to process and understand large amounts of text data. I learned how to break text into smaller parts like words, and then analyze patterns such as frequency, repetition, and structure. This made me realize how powerful simple tools like strings, lists, and dictionaries can be when combined together.

One of the most important ideas was cleaning text before analyzing it. Raw text often contains punctuation, capitalization differences, and formatting that can affect results. By normalizing the text, such as converting everything to lowercase or removing punctuation, the analysis becomes more accurate and meaningful.

I also learned how to count word frequencies using dictionaries, which connects back to the previous chapter. This helped me see how different concepts build on each other. Another interesting idea was identifying common words versus unique words, which can reveal patterns in writing style or content.

This chapter felt especially relevant because it connects directly to real world applications like analyzing reviews, social media, or job descriptions. It also reminded me of my machine learning class at Babson where I used R for text mining. It was interesting to apply similar concepts in Python and see how the process works step by step instead of relying on libraries.

## Challenges I faced

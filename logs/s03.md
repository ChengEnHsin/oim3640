Notes from text book:

Chapter 1 — Programming as a Way of Thinking


1. Purpose of the Chapter

Introduces programming as both a practical skill and a way of thinking.

Emphasizes “thinking like a computer scientist,” which combines logic, precision, experimentation, and problem-solving.

2. Key Concepts
1.1 Arithmetic Operators

Python supports common arithmetic operators:

+ addition

- subtraction

* multiplication

/ division (always returns a float)

// floor (integer) division

** exponentiation

Operator precedence follows standard math rules.

Parentheses can be used to control evaluation order.

1.2 Expressions

An expression is a combination of values and operators.

Expressions evaluate to a value.

Examples:

2 + 3
5 * (10 - 2)

1.3 Arithmetic Functions

Python provides built-in functions for numbers:

round(x) rounds to the nearest integer

abs(x) returns the absolute value

Function calls always use parentheses.

1.4 Strings

Strings are sequences of characters enclosed in quotes:

Single quotes 'hello'

Double quotes "hello"

String operations:

+ concatenates strings

* repeats strings

len() returns the length of a string.

1.5 Values and Types

Every value has a type:

int, float, str

Use type() to check the type of a value.

Quoted numbers (e.g., "123") are strings, not integers.

1.6 Formal and Natural Languages

Natural languages evolve and tolerate ambiguity.

Programming languages are formal and require exact syntax.

Computers interpret code literally and precisely.

1.7 Debugging

Errors in programs are called bugs.

The process of finding and fixing them is debugging.

Debugging is a normal and essential part of programming.


Chapter 2 — Variables and Statements


1. Focus of the Chapter

Introduces variables, assignment, statements, and basic program structure.

Builds on expressions and values from Chapter 1.

2. Key Concepts
2.1 Variables

A variable is a name that refers to a value.

Assignment syntax:

x = 10
message = "hello"


Assignment does not produce output.

2.2 State Diagrams

State diagrams visually represent variables and the values they reference.

Helpful for understanding how values change over time.

2.3 Variable Names

Must begin with a letter or underscore.

Can contain letters, numbers, and underscores.

Cannot start with a number.

Convention: use lowercase letters and underscores.

2.4 Import Statements

Used to access code from other modules.

Example:

import math


Enables reuse of existing functionality.

2.5 Expressions vs Statements

Expressions evaluate to values.

Statements perform actions.

Examples:

Expression: 2 + 3

Statement: x = 5

2.6 The print() Function

Displays output to the screen.

Can print strings, variables, and expressions.

print(x)
print("Hello")

2.7 Arguments

Arguments are values passed into a function.

Example:

print("Python")

2.8 Comments

Comments start with #.

Used to explain code or leave notes.

Ignored by Python during execution.

2.9 Debugging

Common errors include syntax mistakes and undefined variables.

Reading error messages carefully is an important skill.

What I learned this week

This week helped me understand how different data structures in Python work together and when to use each one. In Chapter 10, I learned about lists and how they store collections of data that can be changed. Lists are mutable, which means I can update, add, or remove elements. I practiced indexing, slicing, and looping through lists, and I now understand how iteration makes working with large datasets much easier. I also learned about list methods like append, pop, and sort, which simplify data manipulation.
In Chapter 11, I learned about dictionaries and how they store data as key value pairs. This felt more intuitive for problems where I need to map one thing to another, like counting word frequencies or storing stock prices. I learned how to add and update entries, and I understood that keys must be unique. The get method stood out because it prevents errors when accessing missing keys. Dictionaries made me realize how powerful Python can be for data analysis tasks.
In Chapter 12, I learned about tuples and how they differ from lists. Tuples are immutable, which means they cannot be changed after creation. At first this seemed limiting, but I now see that it is useful for protecting data and ensuring consistency. I also learned about tuple unpacking and how functions can return multiple values using tuples. The zip function was especially helpful because it allows me to combine multiple lists and iterate through them together.
Overall, this week helped me see the bigger picture. Lists are useful for flexible collections, dictionaries are best for mapping relationships, and tuples are helpful when I want stable, unchangeable groupings of data. Understanding the differences between these structures makes me more confident in choosing the right tool depending on the problem.
Challenges I faced
One challenge was understanding when to use each data structure. Lists, dictionaries, and tuples can sometimes solve similar problems, so choosing the right one requires more thinking.
Another difficulty was aliasing with lists. I sometimes accidentally modified the original list when I meant to create a new one. For dictionaries, I had to adjust to using keys instead of indexes, and I ran into errors when accessing keys that did not exist.
With tuples, the biggest challenge was understanding why immutability is useful. It took time to shift my mindset and see it as a benefit rather than a limitation.

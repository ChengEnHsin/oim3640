
## What I learned this week

This week focused on understanding how iteration works and how algorithms are built step by step in Python.

In Chapter 8, I learned more about how `while` loops control repetition in a program. A loop keeps running as long as its condition stays True, so it is important that something inside the loop eventually changes the condition. Otherwise the program will run forever. This helped me understand why updating variables inside loops is essential. I also learned about using counters and accumulators to keep track of values while a loop runs.

Another important idea was thinking about programs as algorithms. Instead of jumping straight into writing code, we should think about the logical steps needed to solve a problem. Breaking problems into smaller steps makes them easier to implement and debug.

In Chapter 9, debugging strategies became clearer. Bugs are normal in programming, and learning how to systematically find them is an important skill. I learned that printing intermediate values can help track what the program is actually doing. Instead of guessing what went wrong, we can inspect variables and follow the flow of the program step by step.

Overall, this week helped me see programming less as writing lines of code and more as designing a process. Understanding loops, algorithmic thinking, and debugging makes it easier to solve problems in a structured way.


## Challenges I faced

The most difficult part this week was tracing loops and understanding how variables change over time. When I first read a loop, it is sometimes hard to picture how many times it will run and what the variables will look like after each iteration.

Another challenge was learning how to debug effectively. When a program does not work, my first instinct is to keep changing random parts of the code. However, this week helped me realize that debugging should be more systematic. Printing variable values or testing smaller pieces of code can make it easier to find the exact problem.

I also realized that thinking algorithmically is still new for me. Sometimes I understand the final goal of the program but struggle to break it into logical steps before writing the code.

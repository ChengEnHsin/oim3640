In this session we continued practicing how loops, flags, and return statements determine what a function actually checks. The main theme is that the final value returned often depends on how a variable is updated inside the loop and whether it keeps previous information or overwrites it.

In `check_vowel(s)`, the function loops through each character and repeatedly assigns `result = (c in 'aeiou')`. However, because `result` is overwritten on every iteration and only returned after the loop finishes, the function only reflects the condition for the last character of the string. It does not check whether the string has any vowel overall; it only checks whether the final character is a vowel. For `check_vowel('orange')`, the last character is `'e'`, which is a vowel, so it returns True. For `check_vowel('lemon')`, the last character is `'n'`, not a vowel, so it returns False. For `check_vowel('kiwi')`, the last character is `'i'`, a vowel, so it returns True. This function actually checks whether the last character is a vowel.

In `any_vowel(s)`, the function correctly accumulates information using a flag variable. It starts with `flag = False` and updates it using `flag = flag or (c in 'aeiou')`. Once a vowel is found, `flag` becomes True and stays True for the rest of the loop. This function properly checks whether any character in the string is a vowel. For `any_vowel('rhythm')`, there are no vowels, so it returns False. For `any_vowel('cafe')`, there are vowels, so it returns True. For `any_vowel('sky')`, there are no vowels from the set `'aeiou'`, so it returns False.

In `all_alpha(s)`, the function starts with `flag = True` and updates it using `flag = flag and c.isalpha()`. If any character is not alphabetic, `c.isalpha()` becomes False and the flag turns False permanently. This function checks whether all characters in the string are letters. `all_alpha('Babson')` returns True because all characters are letters. `all_alpha('OIM3640')` returns False because digits are not alphabetic. `all_alpha('hello!')` returns False because the exclamation mark is not a letter.

In `has_space(s)`, there is a logic mistake. The function loops through characters and checks `if c == ' ': break return True`. However, the `return True` is placed after `break`, which means it will never execute. When a space is found, the loop breaks and exits, but then the function continues to the final `return False`. Therefore, this function always returns False. `has_space('ice cream')`, `has_space(' hello')`, and `has_space('pizza')` all print False, even though the first two strings contain spaces. The `return True` is unreachable code.

Finally, in `all_digit(s)`, the function checks each character and immediately returns False if any character is not a digit. If the loop completes without finding a non-digit character, it returns True. This function correctly checks whether all characters in the string are digits. `all_digit('911')` returns True because all characters are digits. `all_digit('3.14')` returns False because the period is not a digit. `all_digit('OIM3640')` returns False because letters are not digits. This function is correct because it only returns True after verifying every character, and it exits early only when it detects a failure condition.

My Project Proposal

**What are you building?**

I am building a Python based internship and job application tracker that organizes applications and generates insights such as response rates, timelines, and role preferences.



**Why?**

During recruiting, I often track applications across multiple platforms and it becomes disorganized quickly. I want a centralized system that not only stores my applications but also helps me analyze patterns in my recruiting process. This project solves the problem of messy tracking while adding a data driven layer to improve how I approach applications and decision making.



**MVP vs. Stretch Goals**

**MVP (Minimum Viable Product):**

* Store applications using a list of dictionaries in Python
* Each application includes company, role, date applied, status, and location
* Ability to add new applications
* Ability to update application status
* Print a summary of all applications
* Calculate basic statistics such as total applications and response rate

Stretch Goals:

* Add data visualization such as applications over time and success rate by role
* Export data to CSV for external use
* Build a simple command line interface for better user interaction
* Add deadline tracking or priority scoring
* Explore simple prediction of which roles lead to more interviews


**What don’t I know yet?**

I am still figuring out how to structure a clean and user friendly command line interface. I also need to learn how to create clear visualizations using Python and how to store data so that it persists between runs. Additionally, I want to explore how to design more meaningful metrics beyond simple counts, and I am unsure how complex the analysis should be at this stage.
